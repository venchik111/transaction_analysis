# Transaction Analysis

Учебный проект для анализа банковских операций. Формирует JSON для главной страницы, ищет операции по описанию и категории, сохраняет отчет о тратах по категории в Excel.

## Установка и запуск

Нужны Python 3.14 и Poetry. Из папки проекта:

```bash
git clone https://github.com/venchik111/transaction_analysis.git
cd transaction_analysis
poetry install
cp .env_template .env
poetry run python -m src.main
```

В `.env` укажите `ALPHA_VANTAGE_API_KEY`. Бесплатный ключ можно получить на [сайте Alpha Vantage](https://www.alphavantage.co/support/#api-key). Валюты и акции задаются в `user_settings.json`. Курсы возвращаются к рублю, цены акций — в долларах. Используются последние доступные котировки, а не исторические. Запросы отправляются с паузой в одну секунду, чтобы соблюдать ограничение бесплатного ключа. При недоступном API или превышении суточного лимита соответствующее значение в JSON будет `null`.

В общем меню доступны:

1. Главная — дата и время, например `2021-12-20 23:59:59`.
2. Поиск — строка, например `супермаркеты`. Регистр не важен; пустой запрос возвращает все операции.
3. Отчет — категория, например `Супермаркеты`, и дата `2021-12-20`. Пустая дата означает сегодня. Результат сохраняется в `reports/spending_by_category.xlsx`.
4. Обработка операций из JSON, CSV или XLSX — прежнее меню Bank Project с фильтрацией по статусу, сортировкой по дате, отбором рублевых операций и поиском по описанию.

Для главной и отчета учитываются успешные операции `OK`. Расходы — отрицательные суммы платежей. Главная берет данные с начала месяца до указанного момента; топ-5 сортируется по числовой сумме платежа по убыванию. Отчет выбирает расходы за три календарных месяца назад, включая весь последний день. Функция отчета возвращает DataFrame, а декоратор сохраняет его в Excel; другое имя файла задается через `@save_report("reports/my_report.xlsx")`.

## Данные и модули

В `data/operations.xlsx` находится [копия учебной выгрузки](https://github.com/ku93/cours_1/blob/taskk1/data/operations.xlsx): 6705 операций за 2018–2021 годы. 24.10.2026 она сверена с [исходным файлом по новой ссылке урока](https://docs.google.com/spreadsheets/d/1lH0Vs61N7AXviwLCFn0u9H3mDGI3opHO/edit): все значения и пропуски в 6705 строках и 15 столбцах совпадают. Форматы файлов отличаются: исходник — `.xls`, файл проекта — `.xlsx`. Для непустых примеров используйте даты из периода выгрузки.

В `src/utils.py` — чтение данных и настройки; в `external_api.py` — запросы API; в `views.py` — главная; в `services.py` — поиск; в `reports.py` — отчет; в `decorators.py` — декоратор сохранения. Логи пишутся в `logs/app.log` при запуске через меню.

## Основа проекта и Git Flow

Проект продолжает код и Git-историю `bank_project` из PR №9. Единая точка входа —
`src/main.py`: задачи курсовой и прежняя обработка файлов доступны в общем меню.
Запуск: `poetry run python -m src.main`.

- `main` — готовая версия курсовой.
- `develop` — собранная курсовая.
- `feature/coursework-data` — настройки и чтение Excel.
- `feature/coursework-search` — простой поиск на основе `process_bank_search`.
- `feature/coursework-report` — отчет и декоратор сохранения.
- `feature/coursework-home` — главная страница и котировки.
- `feature/coursework-run` — запуск примеров и документация.

Каждая feature-ветка содержит небольшие коммиты и сливается в `develop` через merge.
Новый загрузчик `load_operations` и прежний `load_transactions_excel` используют общий `read_excel_file`,
поиск расширяет `process_bank_search`, форматирование дат использует `get_date`.

## Сверка с заданием

Выбрано по одной задаче из каждой категории: «Главная», «Простой поиск» и «Траты по категории».
Для топ-5 соблюдается сортировка из критериев оценки; порядок в иллюстративном JSON урока отличается.
Расходами считаются отрицательные суммы успешных операций `OK` — это принятое правило обработки данных.

Проверены границы времени приветствия, период главной, расчеты по картам, топ-5,
поиск по двум полям и оба варианта сохранения отчета. Отдельные тесты проверяют
пустой Excel с заголовками, русские и ISO-даты, а также прямой вызов отчета
с таблицей из Excel. Для исходной выгрузки результаты дополнительно сверены
с независимым построчным подсчетом.

Для выполнения критерия о котировках нужен действующий ключ API: у всех валют
и акций из настроек должны быть положительные значения. `null` обозначает
недоступную котировку и не заменяет успешную проверку настоящего API.
