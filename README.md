# Bank Project

## Описание

**Bank Project** — учебный Python-проект для работы с банковскими транзакциями.

Программа позволяет загружать информацию о транзакциях из файлов разных форматов, фильтровать и сортировать операции, выполнять поиск по описанию, маскировать номера банковских карт и счетов, а также выводить итоговый список операций в удобном виде.

## Возможности проекта

Программа поддерживает:

- загрузку транзакций из **JSON**, **CSV** и **XLSX** файлов;
- фильтрацию транзакций по статусу:
  - `EXECUTED`;
  - `CANCELED`;
  - `PENDING`;
- сортировку операций по дате;
- фильтрацию операций по валюте;
- поиск операций по слову в описании;
- маскирование номеров банковских карт;
- маскирование номеров банковских счетов;
- преобразование даты в формат `ДД.ММ.ГГГГ`;
- получение описаний транзакций с помощью генератора;
- генерацию номеров банковских карт;
- подсчет количества операций по заданным категориям;
- конвертацию суммы транзакции в рубли через внешний API;
- логирование работы отдельных функций.

## Основные модули

### `main.py`

Главный модуль программы.

Позволяет пользователю:

1. выбрать источник данных: JSON, CSV или XLSX;
2. выбрать статус транзакций;
3. отсортировать операции по дате;
4. оставить только рублевые транзакции;
5. выполнить поиск по описанию;
6. вывести найденные операции.

Для запуска программы:

```bash
python main.py
```

### `src/utils.py`

Содержит функции для чтения файлов:

- `load_transactions()` — загружает транзакции из JSON;
- `load_transactions_csv()` — загружает транзакции из CSV;
- `load_transactions_excel()` — загружает транзакции из XLSX.

### `src/processing.py`

Содержит функции обработки списка транзакций:

- `filter_by_state()` — фильтрует операции по статусу;
- `sort_by_date()` — сортирует операции по дате.

### `src/generators.py`

Содержит генераторы:

- `filter_by_currency()` — возвращает операции в указанной валюте;
- `transaction_descriptions()` — поочередно возвращает описания транзакций;
- `card_number_generator()` — генерирует номера банковских карт в указанном диапазоне.

### `src/masks.py`

Содержит функции маскирования банковских реквизитов:

- `get_mask_card_number()` — маскирует номер банковской карты;
- `get_mask_account()` — маскирует номер банковского счета.

Пример:

```text
7000792289606361
```

преобразуется в:

```text
7000 79** **** 6361
```

### `src/widget.py`

Содержит функции:

- `mask_account_card()` — определяет тип банковского реквизита и маскирует его;
- `get_date()` — преобразует дату в формат `ДД.ММ.ГГГГ`.

### `src/bank_operations.py`

Содержит функции для дополнительной обработки банковских операций:

- `process_bank_search()` — ищет транзакции по строке в описании;
- `process_bank_operations()` — подсчитывает количество операций по заданным категориям.

Поиск выполняется без учета регистра.

### `src/external_api.py`

Содержит функцию:

- `get_transaction_amount()` — возвращает сумму транзакции в рублях.

Для транзакций в иностранной валюте используется внешний API обменных курсов.

### `src/decorators.py`

Содержит декоратор `log()`.

Декоратор записывает информацию:

- о начале выполнения функции;
- об успешном завершении;
- о результате работы;
- об ошибках;
- о переданных аргументах.

Логи могут выводиться в консоль или записываться в файл.

## Установка

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/venchik111/bank_project.git
```

### 2. Перейдите в папку проекта

```bash
cd bank_project
```

### 3. Установите зависимости

Проект использует Poetry:

```bash
poetry install
```

## Зависимости

В проекте используются:

- `requests` — выполнение HTTP-запросов;
- `python-dotenv` — работа с переменными окружения;
- `pandas` — обработка CSV и XLSX файлов;
- `openpyxl` — чтение Excel-файлов;
- `pytest` — тестирование;
- `pytest-cov` — проверка покрытия тестами;
- `flake8` — проверка стиля кода;
- `isort` — сортировка импортов;
- `mypy` — проверка типов.

## Настройка API

Для конвертации валют необходимо создать файл `.env` в корне проекта:

```text
API_KEY=ваш_api_ключ
```

Ключ используется модулем `external_api.py` для обращения к сервису конвертации валют.

## Использование

После установки зависимостей запустите:

```bash
python main.py
```

